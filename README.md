# 🚗 Automatic Emergency Braking System (Day 16)

## 📌 Overview
This project simulates an Automatic Emergency Braking (AEB) system using C programming.

## 💡 Features
- Collision detection logic
- Emergency brake activation
- Warning alerts
- Safety-based decision making

## 🧠 Logic
- Distance < 10 → Emergency brake
- Distance < 25 → Warning alert
- Else → Safe

## 💻 Tech Stack
- C Programming
- GCC Compiler

## 🚀 Run
gcc aeb.c -o aeb
./aeb
